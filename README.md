A keyboard-driven quick launcher / menu (think `rofi`), built for my own daily use and rewritten across a few stacks to explore each one.

| Project | Stack | What it is |
| --- | --- | --- |
| [GUI-KOHA-Rust](https://github.com/zakiburnama/GUI-KOHA-Rust) | Rust | GUI rewrite of KOHA |
| [TUI-KOHA-Go](https://github.com/zakiburnama/TUI-KOHA-Go) | Go | CLI/TUI version of KOHA |
| [win_KOHA](https://github.com/zakiburnama/win_KOHA) | AutoHotkey | rofi-like quick menu for Windows |
